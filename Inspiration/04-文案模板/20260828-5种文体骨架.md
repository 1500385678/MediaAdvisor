> 关联索引:[`00-索引.md`](../00-索引.md) · 关联主计划:[项目开发计划.md §3 第 3 项 / §6 第 3 项](../../项目开发计划.md)

## 用途

为 Phase 1 第 3 项"稿件润色 API:支持 5 种文体切换,保留人设档案" 提供最小可入库骨架。每种文体包含"结构 / 字数 / 开头模板 / 主体模板 / 结尾模板 / 检查项" 6 段,直接喂给 LLM 改写 prompt 即可使用。

---

## 1. 公众号长文

- **字数**:1500-3500 字
- **结构**:`开头钩子(100-200 字) → 主体 3-5 段(每段 300-500 字) → 结尾 CTA(100-200 字)`
- **开头模板**:`[故事/数据/反常识结论] → 引出主题 → 给出"为什么要读完"的承诺`
- **主体模板**:`每段 = 1 个小观点 + 1 个案例/数据 + 1 句过渡到下段`(每段独立可折叠)
- **结尾模板**:`总结 3 个 takeaway + 互动提问(评论区见) + 关注/在看引导`
- **检查项**:`[ ] 开头 3 段内出现核心观点 [ ] 段落独立可读 [ ] 结尾有明确 CTA [ ] 全文配图 ≥ 3 张`

## 2. 小红书卡片

- **字数**:300-800 字(图文笔记) / 50-150 字(纯文字笔记)
- **结构**:`封面标题(20 字内) → 开头 emoji + 痛点共鸣(2 行) → 干货清单(3-7 条) → 结尾求互动`
- **开头模板**:`[emoji × 2] [人群标签] [痛点场景] 吗?我 [意外结果] 👇`
- **主体模板**:`数字编号 + 关键词前置 + 一句解释`(例:`1️⃣ 选题:用"3 类 15 公式"工作流,日更不愁`)
- **结尾模板**:`[emoji × 2] 收藏备用 + 评论区扣 1 给你模板 + 关注不迷路`
- **检查项**:`[ ] 标题含数字或疑问 [ ] emoji 每段 ≥ 2 个 [ ] 标签 3-8 个精准 [ ] 有封面图建议 [ ] 干货清单 ≥ 3 条`

## 3. 短视频脚本

- **字数**:15-60 秒(脚本本体 80-300 字)
- **结构**:`Hook(0-3 秒) → 主体(3-45 秒) → CTA(45-60 秒)`
- **开头模板(3 秒钩子)**:`[强冲突画面 + 一句话悬念] · 例:"我做了 100 条视频才发现,90% 的开头都是错的"`
- **主体模板**:`一段一观点 + 字幕/特效/镜头切换提示(标注 [切镜]/[字幕]/[特效])`
- **结尾模板**:`重复核心结论 + 一句引导(关注/评论/收藏) + 钩子下期`
- **检查项**:`[ ] 前 3 秒能留住人 [ ] 主体每 10 秒有 1 个变化点(切镜/音效/特效) [ ] CTA 明确(关注/评论/收藏) [ ] 字幕关键词完整 [ ] 时长符合平台限制`

## 4. 知乎回答

- **字数**:500-2000 字(短答) / 2000-5000 字(深度长答)
- **结构**:`开门见山给结论 → 论证(数据/案例/类比) → 反方观点回应 → 总结升华`
- **开头模板**:`[一句话给结论] · 例:"先说答案:在 2026 年做小红书,起号最快的还是'垂类深耕 + 借势热点'。" + 一句"为什么这么说"`
- **主体模板**:`分点 + 配图 + 引文`(每点独立,引用权威数据/文献加分)
- **结尾模板**:`[ ] 呼应开头结论 [ ] 给读者一个"可执行的下一步" [ ] 引导点赞/关注(知乎允许但避免硬广)`
- **检查项**:`[ ] 结论前置 [ ] 引用 ≥ 1 处权威数据/文献 [ ] 至少回应 1 个反方观点 [ ] 配图 ≥ 2 张 [ ] 无引导关注/营销话术`

## 5. 微博文案

- **字数**:140 字内(单条) / 微博正文 + 9 图(配图版)
- **结构**:`情绪/事件 → 转折/观点 → 话题标签(2-3 个)`
- **开头模板**:`[情绪爆发或事件陈述] · 例:"今天差点被气哭,同事居然……" 或 "[行业新闻] 我看傻了"`
- **主体模板**:`1 段情绪 + 1 段观点(可选项)`,不超 3 段
- **结尾模板**:`[1 个反问或一句金句] + #[话题 1] #[话题 2] #...#`
- **检查项**:`[ ] 140 字内(超长用图文或长文) [ ] 话题标签 2-3 个精准 [ ] 情绪/观点清晰 [ ] 无违规词 [ ] 配图 ≥ 1 张(数据表明配图曝光 +30%)`

---

## 跨文体适配建议

- **公众号 → 小红书**:长文拆 3-5 张卡片,每卡 = 1 段 + emoji,标题用小红书 5 例公式
- **小红书 → 短视频脚本**:每条干货 = 1 个 3-15 秒视频,3 段卡片 = 30-60 秒口播
- **知乎回答 → 公众号**:深度长答改 1500-3500 字公众号,加入故事开头
- **公众号 → 微博**:长文核心 1 个观点 + 1 个数据 → 缩到 140 字,配 1 张图

## 不做什么

- 不写具体博主风格的"人设档案"模板(主计划 §5 第 5 项专门做)
- 不做行业垂类(美妆/3C/母婴等)细分布局,等 Phase 1 引入"行业话题词库"再扩
- 不写 AI 提示词的完整 prompt 字符串(主计划 §3 LLM 改写 API 时统一封装)
