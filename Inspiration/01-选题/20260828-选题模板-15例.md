## 用途

为 Phase 1 "选题灵感工作台" 提供最小可用选题库:输入主题/关键词 → 在 15 个公式中选 1-3 个组合生成候选。结构按"公式 + 适用平台 + 范例"组织,使用时可搭配 [_MediaLib/02-爆款/20260827-小红书爆款标题-30例.md](../02-爆款/20260827-小红书爆款标题-30例.md) 复用爆款标题素材。

## 公式(按"3 类 × 5 例"组织)

### A. 数字型(强吸引力,适合小红书 / 抖音 / 知乎)

1. **数字 + 解决方案 + 目标人群**:`N 个 [方法/技巧],让 [人群] 轻松 [收益]`
   - 适用:小红书种草、知乎干货、公众号合集
   - 范例:`5 个剪辑技巧,让新手也能剪出电影感 / 3 步打造爆款小红书,素人博主也能破万赞`
2. **数字 + 反常识结论**:`N 个你以为对但其实错的 [领域] 常识`
   - 适用:知乎反驳、公众号观点文
   - 范例:`7 个你以为健康的早餐习惯,其实在毁掉你的胃`
3. **数字 + 时间承诺**:`N 天 / N 小时,让 [目标] 发生 [变化]`
   - 适用:训练营、读书打卡、知识付费
   - 范例:`30 天写作打卡,普通上班族也能写出 10w+`
4. **数字 + 排行 / 测评**:`[数量] 款 [品类] 横向测评,第 [名次] 名出乎意料`
   - 适用:B 站测评、知乎横评、小红书红黑榜
   - 范例:`2026 年 10 款降噪耳机横评,第一名居然不是索尼`
5. **数字 + 清单**:`[人群] 必看的 N 个 [内容]`
   - 适用:抖音清单体、公众号年终盘点
   - 范例:`设计师必看的 8 个 2026 视觉趋势`

### B. 疑问 / 悬念型(高打开率,适合公众号 / 微博 / 视频开头)

6. **疑问 + 痛点场景**:`[人群] 是不是也 [痛点场景]?`
   - 适用:公众号标题、视频开头 3 秒钩子
   - 范例:`你是不是也一开口就紧张,脑子空白?`
7. **反问 + 颠覆常识**:`[常见做法] 真的对吗?`
   - 适用:知乎、公众号
   - 范例:`每天 8 杯水真的对吗?`
8. **悬念 + 留白**:`[事件] 之后,我 [意外结果]`
   - 适用:故事型短视频、公众号情感文
   - 范例:`裸辞 3 个月后,我过上了月入 5w 的生活`
9. **疑问 + 数据反差**:`为什么 [A 数据] 的人,反而 [B 结果]?`
   - 适用:商业分析、知乎长文
   - 范例:`为什么粉丝 10w 的博主,带货收入不如粉丝 5k 的?`
10. **自问自答 + 行动**:`[痛点]?试试这 [N] 招`
    - 适用:小红书、抖音口播、公众号
    - 范例:`选题没灵感?试试这 4 招`

### C. 故事 / 场景型(高完播 / 完读,适合短视频 / 公众号 / 播客)

11. **第一人称 + 时间节点**:`[时间] 那天,我 [转折事件]`
    - 适用:Vlog、公众号情感、播客开场
    - 范例:`2025 年 12 月那天,我决定全职做自媒体`
12. **人物 + 冲突 + 结果**:`[身份] [冲突],最后 [反转结果]`
    - 适用:抖音剧情号、公众号人物特写
    - 范例:`农村出身的北漂程序员,3 年后逆袭成了产品总监`
13. **场景描写 + 痛点共鸣**:`[场景白描],[人群] 的 [痛点] 突然被戳中`
    - 适用:小红书、抖音情感号
    - 范例:`凌晨 2 点,我盯着天花板,突然意识到我已经 3 年没涨过薪了`
14. **对比 + 转折**:`[旧状态] → [转折事件] → [新状态]`
    - 适用:成长类短视频、公众号复盘文
    - 范例:`月入 3000 → 月入 5w,我只做对了一件事`
15. **身份代入 + 决策点**:`如果你是 [身份],面对 [决策],你会 [选择]?`
    - 适用:知乎、播客、B 站互动视频
    - 范例:`如果你是 30 岁的产品经理,接到 60w 年薪的 offer,但要去新一线城市,你会去吗?`

## 组合用法

- **A + C 混搭**:数字开篇给承诺,故事承接给代入(适合长视频 / 公众号长文)
- **B + A 收尾**:疑问钩子开头,数字清单收口(适合小红书 / 知乎)
- **纯 C 系**:故事全程代入(适合 Vlog / 播客 / 情感号)

## 不做什么

- 不写具体平台的数据(点赞/阅读量)预测,这些靠 Phase 1 数据复盘工具产出
- 不做 A/B 测试,15 个公式只提供"灵感起点",不替代"实测验证"
- 不覆盖垂直行业(美妆/3C/母婴等)细分模板,等 Phase 1 引入"行业话题词库"再扩
